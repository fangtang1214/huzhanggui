# 狐掌柜-直播样品管理系统

面向直播带货公司的内部样品管理系统。它把“商品款式”和“实物样品”分开管理：同一货号可以有多件实物，每件实物都有独立编号、Code 128 条形码、当前位置和完整流转记录。

## 已实现功能

- 商品到样登记：商品基础货号按 `两位年份 + 两位月份 + 当月四位商品序号` 自动生成，例如 `26080001`；当月商品序号每月重置，每件实物再追加三位独立序号，例如 `26080001-001`。升级前生成的 `HZG-年份-序号` 等历史货号和旧标签保持原样，并继续支持查询与扫码。
- 商品 API 标识：通过带货助手和联盟机构 API 保存 `product_id`、`out_product_id` 的当前值与历史值；商品列表展示当前 ID，详情页展示历史 ID，不从商品链接数字反解析。
- 图片同款识别：商品 ID 相同直接关联；否则由当前 GLM 模型批量定位新图主体，3 秒未返回时并行启用免费 Flash 后援，7 秒停止等待；服务器本地 AI 只比较新旧主体特征并筛出最多 5 个疑似同款，由人员最终确认。
- 识别管理与纠错：管理员可调严格、标准、宽松三档灵敏度，查看历史索引进度与识别记录；有相应权限的账号可纠正误判合并。
- 逐件实物管理：按到样数量自动创建独立编号，每件样品分别记录到样日期。
- 位置全程追踪：商务部具体位置、各直播间以及已退样、已损坏、已丢失、已赠送。
- 单件与批量流转：有权限的账号可直接修改位置或状态，备注选填，每件样品都会留下独立操作记录。
- 手机扫码：跨浏览器识别 Code 128 条形码，支持实时摄像头、拍照识别和手动输入独立编号，并兼容已有二维码。
- 权限管理：每个账号直接配置功能权限并归属一个部门；拥有查看权限的账号可以查看全公司的相关业务数据，唯一超级管理员固定拥有全部权限。
- 搜索与统计：首页统计、商品与实物筛选、位置分布、完整流转和操作日志。
- Excel 导出：商品档案、实物样品和流转记录。
- 企业微信表格同步测试：超级管理员可生成只读商品库网址，将未归档商品以 UTF-8 CSV 提供给企业微信普通在线表格测试外部取数；同步密钥仅展示一次，网站只保存不可还原的校验值。
- 数据备份：每天北京时间凌晨 03:00 自动备份，滚动保留最近 30 天；管理员也可手动备份、下载或删除。
- 橱窗推广链接：先用达人 API 获取橱窗商品 ID，再同步全部已启用机构账号下的“商家指定达人佣金”和“机构分配达人佣金”合作商品。链接按“机构分配达人佣金优先 → 同类型下主机构账号优先 → 同类型、同主账号条件下机构服务费率最高”选择；没有机构分配链接时回退商家指定链接，同优先级且服务费率相同或替换已确认链接时由人员确认。
- 橱窗登记：同步只按微信商品 ID 关联已有档案，不自动登记新商品；未登记商品必须人工进入登记页，并继续通过图片疑似同款确认流程。
- 商品 ID 快捷登记：在手动登记入口填写 `out_product_id`，系统会实时查询全部已启用联盟机构账号，并按“机构分配链接 → 主机构账号 → 机构服务费率最高”的顺序取得最新商品资料；ID 已关联时直接进入同款更新，未关联时继续执行图片疑似同款确认。
- 电脑与手机响应式界面，所有页面登录后才能访问。

> 商品图片仅保存外部网址，不上传图片文件。图片识别只在内存中短暂读取原图，数据库仅保存网址与小型特征数据；同一网址会直接复用特征，不重复读取原图。

## 服务器要求

- Ubuntu 22.04 或 Ubuntu 24.04
- 建议至少 2 核 CPU、4 GB 内存、20 GB 磁盘（图片识别模型会缓存在服务器上）
- 一个已经解析到服务器公网 IP 的域名
- 服务器开放 80 和 443 端口

## 一键安装

在已经解析好域名的 Ubuntu 服务器上执行：

```bash
curl -fsSL https://raw.githubusercontent.com/fangtang1214/huzhanggui/main/install.sh | sudo bash
```

安装过程会询问：

1. 系统域名；
2. 初始管理员账号；
3. 管理员姓名；
4. 管理员密码。

安装脚本会自动准备运行环境、数据库、HTTPS 证书和每日备份。完成后直接访问 `https://你的域名`。

## 更新系统

登录服务器后运行：

```bash
sudo bash /opt/huzhanggui/update.sh
```

更新不会删除已有数据库、样品记录和备份。

首次升级到支持网页更新的版本时，请执行一次最新版更新脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/fangtang1214/huzhanggui/main/update.sh | sudo bash
```

完成后，超级管理员可在网站的“系统管理 → 系统更新”中直接更新；普通账号不会显示入口，服务端也会拒绝非超级管理员请求。每次更新前会自动创建数据库备份。

从旧版“斯源直播样品管理系统”首次升级时，请直接运行最新版迁移脚本：

```bash
curl -fsSL https://raw.githubusercontent.com/fangtang1214/huzhanggui/main/update.sh | sudo bash
```

迁移脚本会先自动创建数据库备份，然后将安装目录、数据库、数据库账号、Docker 数据卷和项目标识迁移为 `huzhanggui`。原有账号、权限、商品、样品、流转记录、备份与图片识别模型都会保留。升级完成后，旧路径 `/opt/siyuan` 会作为兼容入口继续可用。旧版的本地更新命令也不会连接到新空数据卷；如果先使用了旧命令，再运行一次上面的最新版迁移脚本即可完成技术标识迁移。

首次启动图片识别时，服务器会自动下载、缓存并预热 Q8 本地模型，初始化可能需要几分钟；系统就绪后，登记人员不会再承担模型冷启动等待。登记时为保证正常情况下 10 秒内返回，最多取前 8 张有效新图，按每批最多 4 张、最多 2 批并行定位；主体框返回后立即进入本地特征队列，个别图片失败时使用其余成功图片继续判断并明确提示覆盖情况。历史图片保存后由后台逐步建立主体索引。相似主体检索使用 pgvector HNSW 索引，历史图片增长后也无需逐条扫描。

如果服务器已经运行 Nginx 并占用了 80、443 端口，更新脚本会自动切换到 Nginx 兼容模式，并依次从 `8800`、`8000`、`8080`、`8008` 中选择一个空闲端口。应用仅监听服务器本机地址，再由现有 Nginx 反向代理，以继续使用域名 HTTPS。

## 首次使用建议

1. 使用安装时创建的管理员账号登录；
2. 在“部门管理”中创建各直播间；
3. 在“位置管理”中创建商务部的仓库、货架或存放区域；
4. 在“账号管理”中创建员工账号、选择所属部门并直接勾选权限；
5. 开始登记商品和到样数量。

## 企业微信在线表格同步测试

1. 使用超级管理员账号进入「系统管理 → 表格同步」。
2. 点击「生成同步密钥」，先打开商品库网址确认可以看到 CSV 数据。
3. 复制页面生成的 `IMPORTDATA` 测试公式，在企业微信普通在线表格中新建名为「商品数据源」的工作表，并将公式粘贴到 A1。
4. 如果表格成功展开数据，再在业务工作表中使用 `VLOOKUP` 或其他查找公式按货号读取价格、商品链接和主图链接。

同步网址包含只读密钥，请勿发送到无关群聊或公开文档。网站不会保存密钥明文；如果离开页面前没有保存网址，需要重置密钥，旧网址会立即失效。企业微信是否支持 `IMPORTDATA` 外部取数需以实际表格结果为准。

## 数据备份与恢复

系统每天生成 PostgreSQL 压缩备份，保存在独立数据卷中。管理员可以在“数据备份”页面下载备份文件到本地长期保存。

恢复数据库属于高风险操作。需要恢复时，请先停止录入，并由服务器维护人员按以下方式处理：

```bash
cd /opt/huzhanggui
docker compose stop app backup indexer
docker compose exec -T database dropdb -U huzhanggui --if-exists huzhanggui
docker compose exec -T database createdb -U huzhanggui huzhanggui
docker compose exec -T database pg_restore -U huzhanggui -d huzhanggui --clean --if-exists < 你的备份.dump
docker compose start app backup indexer
```

## 本地开发

本项目使用 Next.js、PostgreSQL 和 Docker。开发环境需要 Node.js 22 及 PostgreSQL 15 或更高版本。

```bash
npm install
cp .env.example .env
npm run db:bootstrap
npm run dev
```

默认访问地址为 `http://localhost:3000`。
